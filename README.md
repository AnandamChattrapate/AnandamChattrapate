# ⭐ Featured Project

## ⚔️ DualDev

A real-time competitive coding platform inspired by multiplayer games.

### Features

- ⚡ Instant matchmaking
- 🔴 Live Socket.io communication
- 🤖 AI-assisted judging
- 🧠 Redis powered queues
- 🐳 AWS Lambda isolated execution
- 💻 Monaco powered code editor
- 🏆 Live leaderboards
- 📈 Rating system
- 👥 Private battle rooms

---

## Architecture

| Layer | Stack |
|:------|:------|
| Frontend | React • Vite • TailwindCSS • Monaco Editor |
| Backend | Node.js • Express • Socket.io • BullMQ |
| Cloud | AWS EC2 • AWS Lambda • Docker |
| Database | MongoDB • Redis |
| AI | Groq • Llama 3.3 70B |
